# 平台与操作说明

## 支持范围

- **仅支持 HarmonyOS PC 系统**（应用配置 `deviceTypes: 2in1`）
- 典型设备：鸿蒙 **2in1**、折叠 PC、台式 / 笔记本形态的鸿蒙 PC

## 操作方式

- **键盘 + 鼠标**（推荐且为当前主要适配目标）
- **不支持触屏操作**（触屏点击不作为正式玩法，请勿按手游方式使用）

## 不支持

- 鸿蒙 **手机**
- 鸿蒙 **平板**
- 非鸿蒙 PC 的其他 HarmonyOS 设备形态（若系统未按 PC/2in1 提供键鼠与窗口能力）

## 仓库简介（可复制到 GitHub About）

Voxera 鸿蒙版：基于 Luanti 的方块沙盒客户端，仅支持鸿蒙 PC（2in1），键鼠操作，不支持手机/平板与触屏。
